# Работа с движком

- Перед изменениями прочитайте `README.md` в этом каталоге и соответствующие тесты.
- Сохраняйте C++17 и разделение: объявления в `.hpp`, реализации в `.cpp`. Короткие операции с векторами и доступа к данным могут оставаться inline.
- Используйте понятные имена физических величин. Числовые коды видов, категорий и полей берите из `body.hpp` и `protocol.hpp`.
- Не добавляйте комментарии в код. Инструкции и объяснения алгоритмов размещайте в `engine/README.md`.
- Состояние и рабочие буферы принадлежат `Runtime`, `Solver` или `BroadPhase`. Не вводите общие изменяемые переменные, статические буферы или неявный текущий источник импульсов.
- Передавайте источник импульса явно и сохраняйте учёт сил и моментов при изменении движения.
- При рефакторинге сохраняйте порядок вычислений, параметры физики и ABI `engine_*`. Изменения формата обмена требуют отдельной согласованной правки Worker и тестов.
- Не меняйте логику и интерфейс фронтенда в рамках работы над ядром. Не редактируйте `TASKS.md` без прямого запроса.
- Добавляйте проверку изменённого поведения в нативные тесты; при новом тестовом файле обновляйте `test.mjs` и `CMakeLists.txt`. Не отключайте `assert` в Release-тестах.
- Из корня запускайте `node engine/test.mjs`, затем `npm --prefix frontend test` и `npm --prefix frontend run build`. Для проверки CMake используйте команды из README. После изменения C++ доставляйте актуальный WASM.

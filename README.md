# Механика

Локальная двумерная физическая песочница. React + SVG — редактор; собственный C++17 — численный расчёт. Сторонних физических библиотек нет.

## Запуск на Windows

Нужны Node.js и g++ в PATH (или путь к компилятору в переменной CXX).

```powershell
cd frontend
npm install
npm run dev
```

Vite компилирует `engine/src/main.cpp` при запуске и обслуживает локальный `/api/step`. `npm run build` проверяет TypeScript и собирает клиент; `npm run preview` обслуживает сборку вместе с движком. Один статический `dist` без сервера симуляцию не запускает.

## Редактор

- Верхняя панель: открыть/скачать JSON, undo/redo, сантиметровая сетка с привязкой 1 мм, запуск/остановка.
- Компоненты добавляются перетаскиванием или нажатием. Индексы уникальны; переименование обновляет связи.
- Выбор тела открывает свойства. Маркеры меняют размеры; угол задаётся в радианах. Координаты и длины в метрах, y направлена вниз.
- Сила и ускорение действуют на выбранные тела в направлении вектора ширина/высота. Скорость задаёт начальную скорость; изменение её величины в запущенной сцене меняет скорость затронутых тел.
- Пружина/нить с одним телом закреплена вторым концом в x,y; с двумя телами соединяет их центры. Подшипник автоматически соединяет пересекаемые центром подшипника тела; одно тело соединяется с миром.
- Для нити можно выбрать неподвижный идеальный блок и два тела. Длина в этой модели — сумма расстояний до оси блока. Вращение блока следует перемещению нити.
- Мышь при симуляции прикладывает ограниченную упругую силу; связи продолжают ограничивать движение. Остановка восстанавливает весь снимок сцены, включая изменённые параметры. Структура связей редактируется до запуска.
- Ctrl+Z / Ctrl+Y (также Ctrl+Shift+Z), Delete. В текстовых полях работают нативные команды редактирования.

## Физическая модель и пределы

Полунеявный Эйлер, шаг не больше 0.5 мс; 24 итерации ограничений на подшаг. Второй закон Ньютона, тяжесть, закон Гука с демпфированием, моменты инерции прямоугольника/диска, вращательные импульсы, SAT-контакты, коэффициент восстановления, кулоновское трение, шарниры, односторонняя нерастяжимая нить. Коэффициент контактного трения — геометрическое среднее коэффициентов тел, поэтому μ=0 отключает трение пары. Покой возникает из баланса контактных импульсов и сил; отдельного символического решателя статики нет.

Это численная модель твёрдых тел, а не реализация всех возможных законов физики. Блок идеален: без собственной инерции и трения, с приближением пути нити через ось; реальная геометрия обхвата, подвижные полиспасты и изгиб гибкой нити пока не реализованы. Прямоугольные контакты используют приближённую одну точку, поэтому сложные штабели и крайние соотношения масс требуют дальнейшего улучшения. Нет непрерывного поиска столкновений: очень быстрые тела могут туннелировать. Экстремальные жёсткости могут быть неустойчивы. Нет символьных выражений для переменных — редактируются числовые значения. Масштаб сантиметра относится к координатам модели, а не физическому размеру экрана.

До 200 объектов. Попарные контакты O(n²). Локальный мост запускает процесс на каждый кадр: на больших сценах расчёт идёт медленнее реального времени, но физический шаг не увеличивается.

## Проверка

`cd frontend; npm test` запускает проверки формата проекта, связей и девять расчётных сценариев C++. Пример для загрузки: `examples/spring.physics.json`.

```powershell
g++ -std=c++17 -O2 engine/src/main.cpp -o engine/build/physics.exe
./engine/build/physics.exe --test
cd frontend
npm run build
npm run lint
```

Самопроверка: свободное падение, F=ma, нить под перетаскиванием, закон Гука, покой на поверхности, μ=0, торможение трением, вращение вокруг шарнира, идеальный блок.
